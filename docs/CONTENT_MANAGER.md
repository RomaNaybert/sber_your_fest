# Как менять фестиваль

Студия — отдельный инструмент команды. Ребёнок играет в `game/`; контент-менеджер открывает `content-studio/`. Правки в студии не меняют опубликованный сайт, пока ответственный не выложит новый пакет.

Кабинет на сайте: https://hpfs.ru/sber/mn/

## Начать работу

Из корня проекта запусти `python3 -m http.server 8899`, затем открой `http://localhost:8899/content-studio/`. Через `file://` студия не работает: ей нужно загрузить игровые данные и список картинок.

1. Открой нужный раздел и поменяй значения. Текущий файл уже загружен; чужой экспорт можно открыть кнопкой «Открыть файл».
2. Нажми «Проверить». Студия показывает ошибки и проверяет игровым движком, что на каждой площадке доступен план на три звезды.
3. В «Проверке и экспорте» нажми «Предпросмотр». Дождись сообщения «Игра подтвердила применение текущих данных». Это новая тестовая сессия с твоими изменениями, без публикации.
4. Скачай проверенный `scenarios.json` или игровой ZIP. Ошибки нужно исправить до скачивания.
5. Передай пакет ответственному за публикацию. После выкладки снова открой игру в официальной песочнице и пройди изменённые площадки.

## Что можно менять самому

| Раздел | Доступные правки |
|---|---|
| Покупки | Названия, описание, цена, вместимость, максимум одинаковых, подходящая сила дождя, картинка из готовой библиотеки, прибавки помощников |
| Площадки | Название и готовый фон, гости, погода, общий бюджет, места на поле, открытые покупки/помощники, задание, совет, текст успеха; копирование площадки и перенос выше/ниже |
| Тексты интерфейса | 274 текстовых полей в версии V14: поиск по фразе или ключу, редактирование без HTML/JS. Число может вырасти при доработке обучения |
| Настройки игры | Название, учебная цель, названия четырёх видов погоды |
| Проверка и экспорт | Ошибки по полям, доступные планы, предпросмотр с подтверждением от игры, JSON и ZIP |

Сохраняй подстановки вроде `{guests}` и `{budget}`: игра заменяет их числами. Нельзя превратить текст в HTML: он показывается как текст. Не вставляй внешние ссылки, QR, сторонние бренды или чужих персонажей.

Бюджет площадки включает стоимость приехавших покупок. Уже открытые предметы и места нельзя просто убрать на следующем шаге: это сломает перенос. Переупорядочивание и копирование удобно, но после него особенно нужна проверка. Доступный план в таблице — техническое доказательство проходимости; детям не нужно выдавать его заранее как единственный рецепт.

## Черновики и экспорт

Студия автоматически сохраняет черновик в localStorage этого браузера и восстанавливает его при открытии. Это черновик редактора, не сохранение детского прогресса. Очистка браузера или другое устройство могут его потерять: для передачи скачай JSON. В настройках есть «Сбросить черновик к опубликованной версии» с подтверждением.

«Скачать игровой ZIP» собирает игру с текущим проверенным JSON. Это подготовка к публикации; кнопка не загружает файлы на сервер. Студия и её черновики не должны входить в детский runtime. В проверяемый вес игры входит весь набор файлов внутри игрового пакета, а не только ZIP после сжатия.

Для ответственного есть запасной CLI:

```sh
python3 scripts/package_content.py /путь/к/scenarios.json --output output/festival-content-package.zip
```

Он проверяет данные настоящим движком, исключает symlinks и студию, считает весь runtime и отказывает при превышении5 000 000байт. Сам ничего не публикует. Отдельная сборка `--web-demo`, если используется ответственным, добавляет веб-адаптер; такой пакет не подменяет поставку для sandbox.

## Когда нужен разработчик

Новая механика, формула звёзд, новый тип предмета/помощника или привязки, новые картинки и анимации, изменение звука, геометрии/жестов, контракта приложения и формата данных. Студия не планирует кампании по календарю, не меняет частоту выдачи игры в приложении, не подключает CMS, не управляет доступом сотрудников и не публикует релизы. Это отдельные задачи, их нельзя обещать как уже готовые.

## Что проверено

`output/playwright/v13-content/acceptance.json`: подтверждены явное включение звука, native SHARING с PNG, отсутствие внешних запросов игры, однократные события, применение редакторских данных в preview и безопасный вывод текста; ошибок в отчёте нет. Это браузерный тест с моделированием native-канала. Дополнительный `output/playwright/content-studio/cabinet-acceptance.json` — PASS: черновик переживает reload и сбрасывается, настройки меняются, дублирование даёт7площадок, браузер скачивает ZIP из88файлов без админки. Engine-агент дополнительно сообщил проверку всех87CRC32 в предыдущем срезе через Python zipfile. Практическое обучение проверяется отдельным tests/v14-practice.mjs.
