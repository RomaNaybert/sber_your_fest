# Твой фестиваль

Небольшая игра о том, как устроить праздник для друзей и уложиться в бюджет. Нужно выбрать еду, музыку, укрытия и украшения. Компания растёт, погода меняется, а покупки можно забрать с собой на следующую площадку.

[Играть](https://hpfs.ru/sber/) · [Кабинет контент-менеджера](https://hpfs.ru/sber/mn/)

## Что внутри

- Шесть площадок и новые проходимые задания после них.
- Помощники Мио и Тая: их можно назначать к предметам, переносить и возвращать вместе с покупкой.
- До трёх звёзд за заботу о друзьях и удачный план расходов.
- Практическое обучение: установка, перенос, возврат, вкладки, помощники и звук. Завершение запоминается в cookie; повтор доступен из справки.
- Анимации, музыка с партиями от покупок, отдельная громкость музыки и эффектов.
- Вертикальная и горизонтальная ориентация, перетаскивание и отмена действий.

## Запуск

```sh
python3 -m http.server 8899
```

Игра: http://localhost:8899/game/  
Кабинет: http://localhost:8899/content-studio/

В игре нет сторонних библиотек, CDN, аналитики и серверной логики. Все картинки, шрифты и данные лежат локально. Звук включается отдельной кнопкой. Игровой пакет занимает около 1,74 МБ без сжатия.

## Кабинет

Можно менять 274 текстовых поля, цены, вместимость и картинки из готовой библиотеки, прибавки помощников, бюджеты, погоду, гостей, места и доступные покупки. Площадки можно копировать и переставлять.

Кабинет сохраняет локальный черновик, проверяет проходимость, показывает игру с текущими правками и скачивает JSON или готовый игровой ZIP. Публикация пакета на сервер выполняется отдельно.

[Подробная инструкция](docs/CONTENT_MANAGER.md)

## Проверки

```sh
node --test tests/engine.test.mjs tests/planner.test.mjs tests/renderer.test.mjs tests/animation.test.mjs
npm install
npx playwright install chromium
node tests/v14-practice.mjs
```

Браузерные проверки используют Chrome. Адрес игры задаётся через `FESTIVAL_TEST_URL`.

## Поставка в приложение

В нативный пакет входит только `game/`. Шаринг и события передаются приложению через существующий канал сообщений. `web-demo/` добавляет системный шаринг для обычного сайта и не входит в нативную поставку. Кабинет тоже поставляется отдельно.

На физическом устройстве в официальной песочнице ещё нужно подтвердить системный шаринг, холодную загрузку и частоту кадров. Браузерные проверки не заменяют эти измерения.

Лицензии шрифтов и иконок сохранены в `game/assets/`.
